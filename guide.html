매장 사용자 관리자 자주 묻는 질문

매장 사용자 안내

하자 개선이 필요한 결과물이 있을 때, 수급사(협력업체)에 요청서를 작성해 메일로 보내는 방법입니다.

1. 처음 사용할 때 — 매장코드 발급

매장코드는 우리 매장 전용 접속 코드입니다. 매장당 한 번만 발급하면 됩니다.

  1. 첫 화면에서 매장코드 신규 발급을 누릅니다.
  2. 브랜드, 매장명, 매장 담당자명, 담당자 이메일을 입력합니다.
    • 담당자 이메일은 회사 이메일(@eland.co.kr)만 사용할 수 있습니다. 수급사의 회신이 이 주소로 전달됩니다.
  3. 매장코드는 직접 정하거나(영문·숫자·하이픈 5~20자), 비워두면 자동으로 만들어집니다.
  4. 발급을 누르면 매장코드가 크게 표시됩니다. 반드시 기록해 두세요.
  5. 이 코드로 바로 접속을 누르면 바로 사용할 수 있습니다.
매장코드는 매장 접속 비밀번호와 같습니다. 매장 내부에서만 공유하고 외부(수급사 포함)에 알려주지 마세요.
2. 접속하기
  1. 첫 화면의 매장코드 칸에 코드를 입력하고 접속을 누릅니다. 대·소문자는 구분하지 않습니다.
  2. 화면 위쪽에 우리 매장 이름이 표시되면 접속된 것입니다.
사용을 마치면 오른쪽 위 나가기를 눌러 주세요. 30분 동안 사용하지 않으면 자동으로 나가집니다.

코드를 여러 번 틀리면 보안을 위해 15분 동안 접속이 제한됩니다. 코드를 잊었다면 관리자에게 문의하세요.

3. 하자개선요청서 작성·발송
  1. 메뉴에서 하자개선요청서 작성을 누릅니다.
  2. 수급사 선택: 요청을 보낼 업체를 고릅니다. 아래에 현장대리인과 수신 이메일이 표시됩니다.
  3. 수행일자: 해당 업무가 수행된 날짜를 고릅니다. (기본값: 오늘)
  4. 수행장소는 우리 매장으로 자동 입력됩니다.
  5. 수행작업(예: 샐러드바 청소)과 하자 개선 요청사항을 구체적으로 적습니다.
  6. 사진 첨부(최대 5장): 사진 촬영으로 바로 찍거나 앨범에서 선택으로 저장된 사진을 고릅니다. 사진의 × 를 누르면 뺄 수 있습니다.
  7. 요청서 생성 및 발송을 누릅니다.

요청서(PDF)가 자동으로 만들어져 수급사에 메일로 발송됩니다. 완료되면 "메일로 발송되었습니다" 안내가 나옵니다.

메일 제목[브랜드][매장명] 하자개선요청서
첨부하자개선 요청서 PDF (입력 내용 + 사진)
수급사 회신발신 주소가 아닌 매장 담당자 이메일로 전달됩니다.
매핑 정보 수정을 누르면 요청서에 표시될 수급인 회사명·현장대리인명을 이번 건에 한해 고칠 수 있습니다. 수신 이메일 변경은 관리자에게 요청하세요.

사진은 개인정보 보호를 위해 촬영 위치 등 부가 정보를 지우고 크기를 줄여 저장합니다.

4. 발송 이력 확인

메뉴의 발송 이력에서 우리 매장이 보낸 요청서만 확인할 수 있습니다. 문서를 누르면 발송된 PDF가 열립니다.

5. 휴대폰에 앱처럼 설치하기

홈 화면에 추가하면 주소 입력 없이 앱처럼 바로 실행할 수 있습니다.

  • 아이폰(Safari): 화면 하단 공유 버튼(□↑) → 홈 화면에 추가 → 추가
  • 안드로이드(Chrome·삼성 인터넷): 첫 화면의 홈 화면에 설치 버튼, 또는 브라우저 메뉴(⋮ / ≡) → 홈 화면에 추가·앱 설치

관리자 안내

첫 화면 아래쪽 관리자 화면 링크에서 아이디와 비밀번호로 로그인합니다.

로그인 후 관리자 메뉴 상단에 내 계정과 권한이 표시됩니다.

전체 매장코드 목록

모든 매장의 코드, 매장명, 브랜드, 담당자, 이메일, 생성일을 볼 수 있습니다. 매장이 코드를 잊었을 때 여기서 확인해 안내합니다.

[마스터] 각 행의 수정에서 매장코드·브랜드·매장명·담당자 정보를 바꿀 수 있습니다.

  • 매장코드를 바꾸면 해당 매장은 새 코드로만 접속할 수 있으니 반드시 매장에 알려주세요.
  • 코드 유출이 의심되면 새 코드로 바꿔 주세요.
  • 담당자 이메일은 회사 이메일만 가능합니다. 회사 이메일이 아닌 매장은 메일이 발송되지 않습니다.
[마스터] 매장코드 엑셀 일괄 생성

여러 매장의 코드를 한 번에 만들 때 사용합니다.

  1. 전체 매장코드 목록 화면에서 엑셀로 매장코드 일괄 생성을 누릅니다.
  2. 양식 다운로드로 엑셀 양식을 받아 '매장목록' 시트에 매장 하나당 한 줄씩 입력합니다. (브랜드명·작성 방법은 '작성안내' 시트 참고)
  3. 매장코드 칸은 비워두면 자동 생성되고, 직접 정할 경우 영문·숫자·하이픈 5~20자로 입력합니다.
  4. 엑셀 파일 선택으로 작성한 파일을 올리면 내용과 오류 여부가 표로 표시됩니다.
  5. 오류가 없으면 매장코드 N개 생성을 누릅니다.
  6. 완료 후 생성 결과 엑셀 다운로드로 발급된 매장코드 목록을 받아 각 매장에 안내합니다.
한 행이라도 오류가 있으면 아무 매장도 생성되지 않습니다. 표의 '확인' 칸에 표시된 오류를 엑셀에서 고친 뒤 다시 업로드하세요. 한 번에 최대 300개까지 등록할 수 있습니다.
수급사 관리

요청서를 받을 수급사(협력업체) 목록입니다. 매장의 수급사 선택 목록에 그대로 표시됩니다.

[마스터] + 수급사 추가 또는 각 행의 수정에서 업체명, 현장대리인명, 수신 이메일을 등록·변경합니다.

수급사 현장대리인의 성명·이메일은 개인정보입니다. 등록 전 개인정보 수집·이용 동의서를 받아 주세요.
전체 발송 이력 · 엑셀 다운로드
  1. 조건 선택: 매장, 수급사, 상태, 수행일자(부터~까지)를 골라 원하는 건만 볼 수 있습니다. 조건 초기화로 전체 보기.
  2. 엑셀 다운로드: 현재 선택한 조건 그대로 엑셀(.xlsx)로 받습니다. 제출일시, 매장, 수급사, 수행 내용, 발송상태, 실패사유가 포함됩니다.
  3. 문서: 발송된 요청서 PDF를 엽니다.

[마스터] 수정에서 수급사, 수행일자·장소·작업, 요청사항, 발송상태를 정정할 수 있습니다. 이력 정보만 바뀌며 이미 발송된 메일과 PDF는 바뀌지 않습니다.

관리자 계정 관리 (마스터)
  1. 관리자 메뉴의 관리자 계정 관리를 누릅니다.
  2. 아이디(영문·숫자 3~30자), 이름, 비밀번호(8자 이상)를 입력하고 관리자 추가를 누릅니다.
  3. 퇴사·이동 등으로 필요 없어진 계정은 목록에서 삭제합니다.

추가된 계정은 일반 관리자(조회·엑셀 전용)입니다.

자주 묻는 질문

매장코드를 잊어버렸어요.

관리자에게 문의하면 매장코드 목록에서 확인해 알려드립니다.

"로그인 시도가 너무 많습니다"라고 나와요.

매장코드나 관리자 비밀번호를 여러 번 틀리면 보안을 위해 15분 동안 제한됩니다. 15분 후 정확한 코드로 다시 시도하세요.

"회사 이메일만 사용할 수 있습니다"라고 나와요.

매장 담당자 이메일은 회사 이메일(@eland.co.kr)만 등록할 수 있습니다. 수급사 회신이 외부 주소로 새는 것을 막기 위한 보안 조치입니다.

발송 상태가 "발송실패"예요.

요청서는 저장되어 있으니 관리자에게 알려 주세요.

관리자: 전체 발송 이력 → 엑셀 다운로드의 실패사유 칸에서 원인을 확인할 수 있습니다. 매장 담당자 이메일이 회사 이메일이 아니라면 매장 정보를 수정한 뒤 다시 작성하도록 안내하세요.

보내려는 수급사가 목록에 없어요.

관리자(마스터)에게 수급사 등록을 요청하세요.

문서를 눌러도 PDF가 안 열려요.

브라우저가 새 창(팝업)을 막았을 수 있습니다. 주소창의 팝업 차단 알림에서 이 사이트를 허용한 뒤 다시 눌러 주세요.

사진이 첨부되지 않아요.

일부 특수 형식의 사진은 불러오지 못할 수 있습니다. 다른 사진을 선택하거나 사진 촬영으로 다시 찍어 주세요. 최대 5장까지 첨부할 수 있습니다.

화면이 예전 모습 그대로예요.

PC는 Ctrl + F5, 휴대폰은 페이지를 새로고침하세요. 앱으로 설치했다면 앱을 완전히 종료했다가 다시 실행하세요.

꼭 지켜 주세요

  • 매장코드와 관리자 비밀번호는 외부에 공유하지 마세요.
  • 공용 기기에서는 사용 후 반드시 나가기를 눌러 주세요.
  • 요청서에는 업무와 관련된 내용·사진만 첨부하고, 사람 얼굴 등 불필요한 개인정보가 찍히지 않도록 주의하세요.
